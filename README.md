# Abracadabra Academy

A tiny magic school for a kid and a parent to work through together. Twelve real tricks across four levels (Apprentice → Sorcerer's Helper → Wizard → Grand Magician). Each trick has a hidden secret, step-by-step instructions, a line to say, and a tip for the grown-up.

Every trick earns three stars: know the secret, practice it three times, show it to someone. Master two tricks in a level and the next level unlocks.

Open `index.html` in any browser. No build, no install. Progress saves in the browser on that device.

To add a trick, append an entry to the `TRICKS` array in `index.html`.
