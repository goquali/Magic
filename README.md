# Abracadabra Academy

A magic school for a kid and a parent to work through together. Twelve tricks across four levels (Apprentice → Sorcerer's Helper → Wizard → Grand Magician), picked for big audience reactions: vanishing water, floating arms, a skewer through a balloon, mind reading.

Four of the tricks run inside the app itself (Crystal Ball, Card Thief, Gray Elephant, Card Detective): the tablet becomes the magic prop, and each one also teaches the real secret behind it. Every trick page has a drumroll button for the big reveal.

Every trick earns three stars: know the secret, practice it three times, fool someone. Master two tricks in a level and the next level unlocks.

Open `index.html` in any browser. No build, no install. Progress saves in the browser on that device.

To add a trick, append an entry to the `TRICKS` array in `index.html`. To add an in-app trick, give it an `app` key and add a matching function to `STAGES`.
